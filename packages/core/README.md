# @brockui/core

Core components — shadcn-with-opinion primitives for data and product UIs.

Targets the 90% of SaaS dashboard needs: charts, metric cards, tables, stats, sparklines.

Each component:
- Built on Radix primitives (where applicable) for accessibility
- Single accent color via `--brock-accent` CSS variable
- Micrographics-first (Tufte data-ink discipline)
- Source attribution prop built-in for chart-style components

Status: **planning**. First component (Metric Card) lives in `apps/docs/components/` during Phase 0 prototyping. Will graduate to this package when stable + registry-shipped.
